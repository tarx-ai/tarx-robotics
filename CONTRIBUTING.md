# Contributing

This repository is the TARX public robotics lane. Prefer upstream PRs over
private patches.

## Quality bar

- One issue, one change. Small, reviewable, tested.
- Search existing issues/PRs before opening anything.
- Sign off commits (`Signed-off-by:`) when the upstream repo requires DCO.
- Do not paste partner, pricing, NDA, or internal hardware docs here.
- Do not open drive-by issues just to create activity.

## Where to send work

1. **Install / docs / embodiment bugs** → NVIDIA Isaac-GR00T or NVlabs GR00T-WBC
2. **Robot I/O, DDS, ROS descriptions** → unitreerobotics repos
3. **TARX overlay, tracker, H2 Plus OS notes** → this repo

## Local check

Keep notes in `docs/STATUS.md`. If an upstream PR lands, add a row to the
contribution table in the README the same day.
